# Production evidence

This real product campaign is retained as a complete creative reference. `provenance.json` pins
the original bytes, selected producer IDs and each packaging adaptation.
`video-prompts.json` holds the actual three retained prompt designs; the selected
suspension request is its second attempt. Producer metadata records the real H3
model/protocol, request/reference hashes and selected Take/Artifact identities.
There are no credentials, live service URLs or reusable submission permissions.

## Decisions worth studying

1. **The product sheet is evidence, not scenery.** Prompts distinguish identity
   from its white contact-sheet layout. Conditioning still allowed detail drift.
2. **Repair at the level that actually controls the detail.** More prompt detail
   reduced incorrect stem ends in the floating shot. The poster, acoustic-space
   centre and signature instead retain real reference pixels under explicit
   authored contours. This gives reliable visible shapes at those chosen views;
   it does not solve unseen geometry or every generated view.
3. **Use one campaign basis for image and film.** Shared type, negative space,
   light colour and product cutouts connect the still and closing shot without
   requiring the poster itself to become a video-model input.
4. **Retain timing evidence.** The 209-frame generated candidates are trimmed
   to the edit. Every cut is a straight cut; do not describe this film as a
   demonstration of match cuts or elaborate transitions.
5. **Keep sound claims honest.** Original sparse synthesis supplies the final
   mix; native H3 sound remains in the files. The original review measured the
   mix and sampled pictures, without a claimed full watch or actual audition.

## Which state was retained

The accepted poster and film are byte-preserved outside `project/`. Poster
authoring is frozen from its actual image Build, not from the later live edited
HTML. Film code and the 192 compositor JPEGs come from the selected final pass.
The two selected provider Takes are imported as video Assets so opening/building
the example cannot accidentally submit another generation task.

[Production notes](production-notes.md) retain creative decisions, methods and
measured results. See [the case README](../../README.md) for setup and current
commands. Existing JPEG inputs are retained unchanged for fidelity.

Packaging changes only paths/identity, source declarations, licensing handoff and
the sound render argument `frames` → `samples` at the same PCM length. No movie,
poster or selected footage was re-encoded to curate the case.
The handoff includes selected media and useful rejected/revised candidate
**grids**, without duplicate generation archives or execution caches.
Production notes are edited for publication; their original hash remains in
`provenance.json` alongside the distributed file hash.
